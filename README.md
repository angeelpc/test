# Typography Quote Art Generator

Python application that generates artistic typography compositions where large text is filled with motivational quotes and custom phrases.

## Features

- Creates large text masks from any word.
- Fills typography with randomly distributed quotes.
- High-resolution output suitable for web and print.
- Customizable fonts, colors, and canvas size.
- Supports branding, posters, social media graphics, and website banners.

## Technologies

- Python
- Pillow (PIL)
- NumPy

## Example Use Cases

- Motivational posters
- Personal branding
- Company banners
- Social media content
- Website hero sections
